title: 使用 Chrome DevTools MCP 远程调试
date: 2023-03-16

---

## 1. 启用 Chrome 远程调试

参考：[Chrome DevTools MCP 官方文档](https://developer.chrome.com/blog/chrome-devtools-mcp-debug-your-browser-session?hl=zh-cn)

1. 打开 `chrome://inspect/#remote-debugging`
2. 确保 Chrome 版本 ≥ 144 并启用远程调试

## 2. 在 Cursor 中配置 MCP

```json
{
  "mcpServers": {
    "chrome-devtools": {
      "command": "npx",
      "args": ["chrome-devtools-mcp@latest", "--autoConnect", "--channel=beta"]
    }
  }
}
```
